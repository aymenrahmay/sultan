▶ Stock Inventory Adjustment | PDF Report & Excel Import
Compare theoretical vs. counted quantities and generate stock moves automatically

Ideal for warehouses, retail, and distribution centers. This module lets you create an inventory adjustment, capture counted quantities, compute shortages/surpluses, and automatically generate stock moves with a printable PDF.

  • ✅ Multiple Inventory Types - All products, selected products, category, lot/serial, manual, Excel import
  • ✅ Automatic Differences - Computes shortages and surpluses instantly
  • ✅ Stock Moves - Generates adjustment moves upon validation
  • ✅ PDF Report - Printable report with all lines, shortages, and surpluses
  • ✅ Multi-Company - Works across multiple companies/warehouses
  • ✅ Excel Import - Load counted quantities from spreadsheet

🔑 1. Acceso y Roles
Grupo Manager
  • Crear ajustes
  • Iniciar inventario
  • Validar / Cancelar
  • Borrar (solo Draft)
Grupo User

  • Ver líneas
  • Sin edición
Requisitos: Acceso a ubicaciones internas y productos.
📂 2. Navegación al Menú
  1. Abre el módulo Inventory
  2. Menú: Operations
  3. Clic en Inventory Adjustments
Inventory → Operations → Inventory Adjustments

Verás todos los ajustes con las siguientes columnas:

➕ 4. Crear Ajuste

  2. Selecciona Location (ubicación interna)
  3. Elige Inventory Type

▶ 5. Iniciar Inventario
  1. Clic en botón Start Inventory
  2. Estado cambia a In Progress
  3. Se generan las líneas automáticamente
Bloqueo: Solo 1 inventario en progreso por ubicación. Completa o cancela antes de crear otro.
📝 6. Editar Líneas
Tabs: Lines (todas), Shortages (faltantes), Surpluses (sobrantes), Moves (después de validar).
CampoDescripción
ProductProducto a contar
LocationUbicación
Lot/SerialLote (si aplica)
TheoreticalCantidad en sistema (solo lectura)
CountedCantidad física (editable)
DifferenceRojo = faltante, Verde = sobrante
📥 7. Importar desde Excel
  1. Tipo: Import from Excel
  2. Adjunta archivo en campo Excel File
  3. Clic en Start Inventory
Formato del archivo
CODEQTYLOT (opcional)
PROD00150LOT-2024-001
PROD00225
  • CODE: Referencia interna o código de barras
  • QTY: Cantidad contada (numérico)
  • LOT: Solo si el producto tiene tracking
  • Formatos: .xlsx, .xls, .csv
✅ 8. Validar Inventario
  1. Revisa todas las líneas
  2. Verifica tabs Shortages y Surpluses
  3. Clic en botón Validate
  4. Estado cambia a Validated
Resultado: Se crean movimientos de stock automáticamente:
• Faltantes → salida de ubicación
• Sobrantes → entrada a ubicación
Importante: Una vez validado NO se puede editar ni cancelar.
📄 9. Reporte PDF
  1. Abre el ajuste validado
  2. Menú: Print → Inventory Adjustment Report
  3. Descarga el PDF
Contenido del reporte
  • Encabezado: Referencia, Ubicación, Fecha, Tipo, Estado
  • Todas las líneas con Teórico, Contado, Diferencia
  • Sección Faltantes (rojo)
  • Sección Sobrantes (verde)
  • Totales: líneas, faltantes, sobrantes
❓ What Odoo versions are supported?

Odoo 19 - Community and Enterprise on-premises are fully supported.

❓ Does this work with multi-company?

Yes, the module supports multiple companies and warehouses.

❓ Can I import counted quantities?

Yes. Use Import from Excel with CODE/QTY/LOT columns (.xlsx, .xls, .csv).

❓ What happens on validation?

Stock moves are created automatically for shortages (out) and surpluses (in) with totals per tab.

❓ Do I need extra Python libraries?

For Excel import, install pandas and openpyxl (pip install pandas openpyxl).
